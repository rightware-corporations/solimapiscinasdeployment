# SOLIMA brand assets

This directory contains application-oriented brand assets for the Landing v2 refactor.

## `solima-compact-mark.svg`

Approved derived compact mark:

```text
SOLIMA S + mosaic
```

Use for small product/app contexts such as the SOLIMA Office mark, compact mobile brand moments, and selected loading/empty states.

It does **not** replace the official horizontal SOLIMA logo.

## `solima-favicon.svg`

Tiny-size adaptation of the compact mark with intentionally reduced mosaic detail.

Use for browser/favicon contexts after the corresponding HTML integration phase.

## Rules

- Keep the official horizontal SOLIMA logo as the institutional master mark.
- Do not add random mosaic fragments as decoration; mosaic indicates brand structure/transition.
- Prefer static SVG/PNG for critical brand recognition.
- Interactive 3D/`3dsvg` is optional progressive enhancement, never a rendering dependency.
- Do not use customer media or private lead images as decorative brand assets.
